# Magic Plate Armor — Windows e Android

Clientes públicos de teste do **Magic Plate Armor**. Baixe os arquivos na [release r14](https://github.com/sabedoriadatorah/MagicPlateArmor-Clients/releases/tag/r14-public-test-20261015).

| Plataforma | Download | Instalação |
| --- | --- | --- |
| Android ARM64 | [APK](https://github.com/sabedoriadatorah/MagicPlateArmor-Clients/releases/download/r14-public-test-20261015/MagicPlateArmor-Android-r14-public.apk) | Transfira o APK para o celular e abra para instalar. Use o aparelho deitado, em landscape. |
| Windows 64 bits | [ZIP](https://github.com/sabedoriadatorah/MagicPlateArmor-Clients/releases/download/r14-public-test-20261015/MagicPlateArmor-Windows-r14-public.zip) | Extraia a pasta inteira e execute `MagicPlateArmor.exe`, mantendo os arquivos e subpastas junto dele. |

O jogo utiliza o servidor de teste e o login individual de cada jogador. Google Login não está configurado nesta versão.

## Estado da versão

Esta é uma **versão de testes**, ainda aguardando validação manual. O teste automático de treino com bots apresentou falha ao iniciar a sessão; a validação completa de partidas, compras e vendas continua pendente. A build Android ainda não foi validada em aparelho físico nesta entrega.

Os pacotes públicos preservam o código e os dados de jogo da r14 e removem a credencial compartilhada dos testes privados. O login por conta e os tickets individuais do servidor continuam sendo o meio de acesso online.

Os checksums dos downloads estão em [SHA256SUMS.txt](https://github.com/sabedoriadatorah/MagicPlateArmor-Clients/releases/download/r14-public-test-20261015/SHA256SUMS.txt). Este repositório distribui os clientes compilados do jogo.
